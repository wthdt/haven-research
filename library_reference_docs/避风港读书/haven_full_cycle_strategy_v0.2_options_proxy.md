# 避风港全周期策略 v0.2：期权代理实施规格

> 状态：独立研究情景  
> 数据区间：2016-07-25 至 2026-07-24  
> 禁止事项：不修改 production workflow、Shadow、Paper/Live、券商订单或
> `outputs/latest`

## 1. 目标

在 v0.1 的 `P恐慌 + S企稳 + G贪婪 + E衰竭 + R权利金` 状态机上，
把以下项目真实地接入逐日净值：

1. 现金担保 Put 权利金、回补、到期损益与接货仓；
2. Protective Put / Put Spread 保险的保费、每日估值与分批兑现；
3. `G + E + R` 控制的 Covered Call 权利金与上涨封顶成本；
4. 价差、滑点、费用、100股颗粒度和现金占用。

## 2. 数据与估值口径

- QQQ 的近月 ATM IV 以每日 VXN 为锚；
- TQQQ IV 使用自身20日实现波动率相对 QQQ 的63日滚动比例放大，区间限制
  为1.8～3.3倍，不使用固定3倍；
- 期权每日以 Black-Scholes 理论中间价估值；
- 期限超过30天时，IV向过去252日中位值缓慢回归；
- 10%虚值 Put 的 IV 相对 ATM 增加15%，Call wing轻微下调；
- QQQ总点差按理论中间价5%估计，TQQQ按7%，每股最低总点差0.02美元；
- 每腿每张开平仓费用0.65美元；
- 月度到期日使用第三个周五附近的实际交易日；
- 所有交易信号延迟一个交易日。

这套口径只追求路径与损益结构接近真实，不能恢复真实逐日期权链，也不能冒充
历史成交。

## 3. Covered Call

| 状态 | 联合门槛 | 最大覆盖 | 目标 Delta |
|---|---|---:|---:|
| `RANGE_CARRY` | `G≥50、E≥40、R≥55` | 25% | 0.20 |
| `GREED_TREND` | `G≥75、R≥70` | 10% | 0.15 |
| `GREED_EXHAUSTING` | `R≥55` | 25% | 0.25 |
| 高度过热且衰竭 | `G≥75、E≥60、R≥60` | 50% | 0.25 |

- 期限目标35天，允许28～50天；
- 有效卖价至少高于现价4%～8%，随状态变化；
- 收取75%初始权利金后回补；
- 距到期5天或短期深度ITM时回补/移仓；
- 恐慌、风险预警和恢复期禁止新卖 Call；
- 恐慌事件结束后锁定10个交易日；
- 毛权利金、净损益和内在价值封顶成本分别记账。

## 4. 现金担保 Put

- 期限目标35天，Delta 0.15～0.20；
- `RANGE_CARRY` 可使用 Put 接货仓；
- `PANIC_STABILIZING_1/2` 只为下一档更低价格少量接货；
- 净接货价必须比当日现价低5%～10%；
- 每张按完整 `K × 100` 现金担保；
- 新开仓后仍保留至少25%自由现金；
- 收取75%初始权利金后可回补；
- ITM到期按100股生成接货仓，不能只记录权利金而忽略指派。

## 5. 保险

主情景使用约75天 Put Spread：

- 长 Put 约 -0.25 Delta；
- 短 Put 约 -0.10 Delta；
- 覆盖50%风险资产；
- 只在 `RISK_WARNING`、`P≥35`、`S<55`、P五日上升至少8分且
  `R≤85` 时建立；
- 单次净保费不超过 NAV 的0.75%，年度毛保费预算不超过1.5%；
- `P≥70` 或保险盈利达到初始净保费100%时，累计兑现25%；
- `P≥85` 或进入 `PANIC_STABILIZING_1` 时，累计兑现75%；
- `S≥55` 且 P下降、风险消失或距到期10天时退出/移仓。

Protective Put 作为结构敏感性对照，不根据样本结果替换主参数。

## 6. 资金与风险

- 主资金分层保持 `基础仓35% / Put接货仓20% / 恐慌储备45%`；
- 同时保留 `50/15/35`、`60/10/30` 对照；
- 账户标准压力损失上限15%、普通单因子6%、杠杆ETF 4%；
- TQQQ 只做压力研究，不进入 Paper/Live；
- 参考 sleeve 为50万美元，并另测10万、25万、50万和100万美元，检查
  100股颗粒度。

## 7. 必须独立输出

- 标的/基础策略收益；
- Call毛权利金、净损益和封顶成本；
- CSP毛权利金、净损益、担保现金和指派次数；
- 保险净投入、净损益及恐慌期贡献；
- 接货仓后续收益；
- 价差、滑点、费用；
- 完整净值、回撤、危机阶段和敏感性。

## 8. 当前研究判定

v0.2 只能判断期权模块在一组合理估值假设下的方向与数量级。进入 Paper 前仍需：

1. 用可靠历史期权链校准实际执行价、偏斜与流动性；
2. 重新设计 v0.1 的 `RECOVERY_RETESTED` 100%事件预算释放；
3. 证明保险能在2018Q4、2020和2022三类压力中稳定改善尾部风险；
4. 证明 Covered Call 的净贡献在不同牛市和震荡阶段都不过度依赖参数；
5. 继续禁止 TQQQ 自动化执行。
